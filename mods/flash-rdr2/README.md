# FlashRDR2 v14 — LSD CHAOS FINAL

This is the intentionally ridiculous final patch.

Core:
- F6: Flash powers on/off
- W: super run
- W + Shift: hyper turbo
- Space: super jump
- F9: emergency reset
- F10: horse/car traffic visual conversion
- F11: LSD CHAOS on/off

Flash powers:
- invincibility
- infinite stamina
- explosive bullets
- super jump
- high forward force
- motion blur
- mildly oversized player without the broken 4x camera/body mess

LSD CHAOS mode:
- animated rainbow HUD
- world time-scale pulses between slow motion and normal speed
- player scale "breathes" between roughly 1.15x and 1.60x
- periodic shockwaves throw nearby NPCs away from you
- Minecraft-ish "voxel rain": crate/block props fall from the sky around the player
- traffic conversion continues independently from Flash mode

Traffic:
- tries external `ironroadster` first
- falls back to base-game BUGGY01
- HUD shows how many mounted NPCs were converted

This stays Story Mode only.
