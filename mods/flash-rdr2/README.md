# FlashRDR2 v5

Story Mode only.

Controls:
- F6: Flash mode on/off
- W: Flash run
- Shift while holding W: unlimited turbo
- Space: native super jump while Flash mode is enabled
- F9: emergency reset

Flash mode:
- Invincibility
- Infinite stamina
- Native RDR2 movement-rate boost instead of raw velocity injection
- Ragdoll disabled while enabled
- Motion blur while running
- Super jump
- Optional external custom ped model via FlashRDR2.ini

The custom costume itself is not bundled; set UseCustomModel=1 and CustomModelName to a registered RDR2 ped model.
