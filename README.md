# FlashRDR2 v12 GIANT + TrafficCars

This repository bundle contains two ScriptHookRDR2 plugins:

1. `FlashRDR2.asi`
   - 4.25x giant player
   - hyper speed
   - invincibility
   - infinite stamina
   - super jump
   - explosive bullets

2. `TrafficCarsRDR2.asi`
   - converts nearby mounted NPCs into visual roadster traffic
   - hides the horse and attaches an addon car shell to it
   - keeps Rockstar's horse road/path AI underneath for stability
   - F10 toggles traffic conversion

For the traffic car visuals, install the external `ironroadster` LML model assets from the RDR2AddonVehicles pack.
