HYPERCAR ADDON PATCH FOR RDR2

This folder is a tuned config for the MIT-licensed RDR2AddonVehicles project:
https://github.com/Silonugget/RDR2AddonVehicles

Original roadster defaults:
topSpeed=250.0
accelMultiplier=0.4

This patch:
topSpeed=420.0
accelMultiplier=1.25

The roadster model names expected by the addon are:
ironroadster
ironroadsterwheel

IMPORTANT:
The actual roadster YDR/YTD model assets are not part of the MIT GitHub source.
Install the RDR2AddonVehicles release/assets first (Nexus mod 5285), then replace
its vehicleconfig.json in your RDR2 game directory with this tuned file.

Requirements from the upstream project:
- AB ScriptHook
- LML Mod Loader
- Vulkan advanced graphics

Menu: F8

This hypercar config is meant as a McLaren-style stand-in until you install a
specific converted McLaren model.
